# Quickstart

## Run Locally
```bash
npm install
npm start
```

Open http://localhost:3000

## Configure Keys
Use the API Config panel in the UI to enter API keys for DeepSeek or Gemini

## Validate Feature
1. Open Knowledge Base panel and save a template
2. Click Generate Questions and confirm questions appear
3. Verify chat shows interviewer questions and AI answers separately
4. Toggle PIP and confirm the same separation is visible
